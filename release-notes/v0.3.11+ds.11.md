## What changes

This release makes the client dial a peer's verified direct address before its relay address. Nothing else changes for uploads, downloads or any command.

### Everyone using the client

- **The dial order.** When a peer publishes several addresses, the client now dials a LAN address first when the peer is behind the client's own public IP address, then a verified direct address, then the relay (skipped when the relay is behind the client's own public IP address), then an unverified address, and a LAN address only when nothing else is known.
- **Why.** Upstream's saorsa-core dials the relay first, so the client reached even nodes it could reach directly through another node's relay, and its connections there lasted only as long as that relay did.
- **Where it comes from.** `vendor/saorsa-core` is saorsa-core 0.29.1 with only the dial order changed: the same copy darwin-node has built with since its `ds.17`, byte for byte (its `VENDORED.md`). The workspace's `[patch.crates-io]` puts it in place of the crates.io release.

### Projects that take ant-core by git

- **Repeat the `saorsa-core` patch line** beside the `ant-protocol` one, with this release's tag: Cargo applies a `[patch]` only in the top-level workspace. Without it, `ant-core` still compiles and dials a relay first, as upstream's does. The README's "Rust Library API" gives the lines.
